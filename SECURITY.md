# Sicherheitsrichtlinie

## Unterstützte Versionen

Sicherheitskorrekturen werden für die jeweils neueste veröffentlichte Version
der Reihe 1.x bereitgestellt. Da Minor- und Patch-Versionen innerhalb von 1.x
abwärtskompatibel sind, erhalten ältere Versionen keine separaten
Sicherheitsupdates; bitte stattdessen auf die neueste Version aktualisieren.

| Version              | Unterstützt |
| -------------------- | ----------- |
| neueste 1.x          | ja          |
| ältere 1.x           | nein        |
| 1.0.0-beta.x, Alphas | nein        |

## Sicherheitslücken melden

Bitte melde vermutete Sicherheitslücken nicht in einem öffentlichen Issue und
veröffentliche keine Echtdaten, Zugangsdaten oder ausnutzbaren Details.

Nutze stattdessen eine der folgenden privaten Kontaktmöglichkeiten:

- GitHubs Funktion **Report a vulnerability** im Bereich **Security** dieses
  Repositories oder
- E-Mail an [security@abiturientia-gymsl.de](mailto:security@abiturientia-gymsl.de).

Beschreibe nach Möglichkeit die betroffene Version, die Voraussetzungen, die
Auswirkungen und nachvollziehbare Schritte zur Reproduktion. Teile sensible
Anhänge erst nach Absprache über einen geeigneten verschlüsselten Weg.

Wir bestätigen den Eingang in der Regel innerhalb von sieben Tagen, bewerten
die Meldung und stimmen das weitere Vorgehen vertraulich ab. Bitte gib uns
Gelegenheit zur Untersuchung und Behebung, bevor Details veröffentlicht werden.
